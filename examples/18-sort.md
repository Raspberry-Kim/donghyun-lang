# 다섯 정수 버블 정렬 (인접 교환)

인접한 두 값이 거꾸로면 바꾸는 과정을 네 번 통과한다. 배열 문법 대신 변수 다섯 개를 쓰고 반복문을 펼쳐 비교 과정을 드러낸다.

## 입력과 출력

- **입력**: 정확히 다섯 정수

- **출력**: 오름차순 (기본값: -2 0 7 7 9)

- **핵심**: 매 통과마다 가장 큰 남은 값이 오른쪽에 고정
