# DNA 염기 2비트 부호화와 해밍 거리

2비트 염기 부호(A = 00, C = 01, G = 10, T = 11)로 참조 서열 AAGGCCTT와 검체 서열 AACGCCTT를 16비트 정수로 묶고, 글자·16진(0x0A5F, 0x065F)·비트로 보인다. 염기마다 두 비트를 비교해 해밍 거리와 변이 위치를 찾는다.

## 입력과 출력

- **입력**: 길이 8, 참조 코드 8개, 검체 코드 8개

- **출력**: 두 서열의 16진·비트, 위치 3 G → C (2비트 다름), 해밍 거리 2비트·다른 염기 1개

- **원리**: 값 = 값 × 4 + 코드, XOR = (비트 차)²

- **서브루틴**: #bits
