# 초를 시간·분·초로 나누기 (단위 변환)

총 초를 3600과 60의 몫·나머지로 분해한다. 시각이 아닌 경과 시간이므로 시간은 24를 넘어갈 수 있다.

## 입력과 출력

- **입력**: 0 이상의 정수 초

- **출력**: 시간·분·초 (기본값: 1시간 1분 1초)

- **핵심**: 서로 다른 단위로 분해

## 해설

- 1행: 프로그램 시작

- 2행: 0 이상의 총 초

- 3행: 음수 시간 거부

- 4행: 한 시간의 초

- 5행: 한 분의 초

- 6행: 시간 = 총 초 / 3600의 몫

- 7행: 시간을 제외한 남은 초

- 8행: 분

- 9행: 초

- 10행: 시간

- 11…18행: 결과 안내 — 문자열 "시간 "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 19행: 분

- 20…23행: 결과 안내 — 문자열 "분 "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 24행: 초

- 25…26행: 결과 안내 — 문자열 "초↵"을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 27행: 끝으로

- 28…58행: 결과 안내 — 문자열 "입력 오류: 초는 0 이상↵"을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 59행: (빈 줄 — 다음 줄 번호를 곱으로 쓰기 쉽게 맞춘 자리)

- 60행: 정상 종료
