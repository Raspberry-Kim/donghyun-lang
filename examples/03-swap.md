# 두 변수 맞바꾸기 (임시 변수)

세 번째 변수를 이용해 a와 b를 교환한다. 대입 순서와 값 보존을 익히는 예제다.

## 입력과 출력

- **입력**: 정수 a b

- **출력**: 교환된 b a (기본값: 42 7)

- **핵심**: t ← a, a ← b, b ← t

## 해설

- 1행: 프로그램 시작

- 2행: 첫째 정수 a

- 3행: 둘째 정수 b

- 4행: 임시 변수 t = a: 덮어쓰기 전에 보관

- 5행: a = b

- 6행: b = t

- 7행: 교환 뒤 a

- 8행: 공백 출력 (코드값 32)

- 9행: 교환 뒤 b

- 10행: 줄바꿈

- 11행: 정상 종료
