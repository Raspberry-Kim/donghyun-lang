# 빠른 거듭제곱 (반복 제곱)

지수를 매번 절반으로 줄여 aⁿ을 계산한다. 단순 n회 곱셈과 달리 반복 횟수가 로그 규모로 줄어든다.

## 입력과 출력

- **입력**: 정수 밑 a, 0 이상의 정수 지수 n

- **출력**: aⁿ (기본값: 1594323)

- **핵심**: 홀수일 때 곱하고, 지수 절반·밑 제곱

## 해설

- 1행: 프로그램 시작

- 2행: 밑 a

- 3행: 지수 n

- 4행: 음의 지수는 이 정수 예제 범위 밖

- 5행: 결과 r = 1

- 6행: 지수가 0이면 출력

- 7행: 짝수 지수면 결과 곱셈 생략

- 8행: 홀수 지수: 결과에 현재 밑을 곱함

- 9행: 지수를 절반으로 줄임

- 10행: 마지막 단계의 불필요한 제곱과 오버플로를 방지

- 11행: 밑을 제곱

- 12행: 다음 비트

- 13행: a의 n제곱

- 14행: 줄바꿈

- 15행: 끝으로

- 16…52행: 결과 안내 — 문자열 "입력 오류: 지수는 0 이상↵"을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동현에 쌓아서)

- 53행: (빈 줄 — 다음 줄 번호를 곱으로 쓰기 쉽게 맞춘 자리)

- 54행: 정상 종료

## 주의

이 예제는 빈 곱의 정의로 0⁰ = 1을 사용한다. 결과나 중간값이 실행기 안전 정수 범위를 넘으면 오류가 난다.
