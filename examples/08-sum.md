# 1부터 n까지 더하기 (누적 합)

곱을 누적하는 팩토리얼과 달리 합을 누적한다. 반복 종료 시의 결과를 n(n+1)/2로 검산할 수 있다.

## 입력과 출력

- **입력**: 0 ≤ n ≤ 100000

- **출력**: 누적 합 (기본값: 5050)

- **핵심**: s + 남은 항의 합이 항상 일정

## 해설

- 1행: 프로그램 시작

- 2행: n: 0 이상의 정수

- 3행: 음수 거부

- 4행: 교육용 반복 상한

- 5행: −n

- 6행: 100000 − n

- 7행: 반복이 지나치게 길어지는 입력 거부

- 8행: 합 s = 0

- 9행: 남은 항 k = n

- 10행: k = 0이면 합 출력

- 11행: s ← s + k

- 12행: k ← k − 1

- 13행: 다음 항 더하기

- 14행: 1부터 n까지 누적 합

- 15행: 줄바꿈

- 16행: 끝으로

- 17…61행: 결과 안내 — 문자열 "입력 오류: n은 0 이상 100000 이하↵"을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동현에 쌓아서)

- 62행: (빈 줄 — 다음 줄 번호를 곱으로 쓰기 쉽게 맞춘 자리)

- 63행: 정상 종료
