# 십진 자릿수의 합 (몫과 나머지)

나머지로 마지막 자릿수를 꺼내고 정수 몫으로 그 자리를 제거한다. 음수는 절댓값으로 계산하며 0의 합은 0이다.

## 입력과 출력

- **입력**: 정수 한 개

- **출력**: 자릿수 합 (기본값: 10)

- **핵심**: n % 10, n / 10의 정수 몫

## 해설

- 1행: 프로그램 시작

- 2행: 정수 n

- 3행: 음수는 절댓값으로 바꿈

- 4행: 자릿수 합 = 0

- 5행: 남은 자릿수가 없으면 출력

- 6행: 일의 자리 = n % 10

- 7행: 자릿수 합에 더함

- 8행: 일의 자리 제거

- 9행: 다음 자릿수

- 10행: 절댓값의 십진 자릿수 합

- 11행: 줄바꿈

- 12행: 정상 종료
