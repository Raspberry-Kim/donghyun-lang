# 약물 농도-시간 곡선과 AUC (사다리꼴 적분)

채혈 시각(분)과 혈중 농도(ng/mL)를 받아 농도-시간 곡선을 막대그래프로 그리고, 곡선 아래 넓이 AUC를 사다리꼴 공식 Σ (t₂ − t₁)(C₁ + C₂)/2로 적분한다. 최고 농도 Cmax와 그 시각 Tmax도 함께 찾는다.

## 입력과 출력

- **입력**: 막대 한 칸 농도 25, 측정점 11개, (분, ng/mL) 쌍

- **출력**: 농도 막대그래프, AUC(0-t) = 5453.750 ng*h/mL, Cmax = 940 ng/mL, Tmax = 90 min

- **공식**: AUC = Σ Δt·(C₁+C₂)/2 (선형 사다리꼴)

- **새 명령**: 뚱띠, 뭉치, 포동이

## 해설

- 1행: 프로그램 시작

- 2행: 막대 한 칸이 나타낼 농도 (ng/mL)

- 3행: 측정점 개수 n

- 4…5행: 동×20현 = '█' 코드값 9608 — 곱과 덧셈으로 2줄에 나눠 쌓는다

- 6…37행: 머리글 — 문자열 "t(min)⇥C(ng/mL)↵"을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동동동동동동현에 쌓아서)

- 38행: 측정점을 다 읽었으면 69번 줄로

- 39행: 시각 t (분)

- 40행: 농도 C (ng/mL)

- 41행: −(이전 시각)

- 42행: Δt = t − t이전

- 43행: C + C이전 (붙여 쓰면 덧셈)

- 44행: Δt × (C + C이전) — 사다리꼴 넓이의 2배

- 45행: 넓이 합에 더한다

- 46행: −C

- 47행: Cmax − C < 0, 즉 새 최고 농도면 49번 줄로

- 48행: 51번 줄로

- 49행: Cmax ← C

- 50행: Tmax ← t

- 51행: t 출력

- 52행: 탭

- 53행: C 출력

- 54행: 탭

- 55행: 막대 칸 수 = C ÷ 한 칸 농도

- 56행: 돌아올 줄(60)

- 57행: 65번 줄(막대 그리기)로

- 58행: (빈 줄 — 다음 줄 번호를 곱으로 쓰기 쉽게 맞춘 자리)

- 59행: (빈 줄 — 다음 줄 번호를 곱으로 쓰기 쉽게 맞춘 자리)

- 60행: 줄바꿈

- 61행: t이전 ← t

- 62행: C이전 ← C

- 63행: 남은 측정점 − 1

- 64행: 38번 줄로

- 65행: 막대를 다 그렸으면 적어 둔 줄로 돌아간다

- 66행: 막대 한 칸

- 67행: 남은 칸 − 1

- 68행: 65번 줄로

- 69…87행: 결과 — 문자열 "AUC(0-t) = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동동동동동동현에 쌓아서)

- 88행: 포동이: AUC = 합 ÷ 2 ÷ 60 (분→시간), 1000배 하면 합 × 25 ÷ 3

- 89…103행: 문자열 " ng*h/mL↵"을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동동동동동동현에 쌓아서)

- 104…118행: 문자열 "Cmax = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동동동동동동현에 쌓아서)

- 119행: 최고 농도

- 120…146행: 문자열 " ng/mL, Tmax = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동동동동동동현에 쌓아서)

- 147행: 최고 농도 시각

- 148…154행: 문자열 " min↵"을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동동동동동동현에 쌓아서)

- 155행: 정상 종료

## 주의

입력값은 설명용 가상 경구약 자료다. 첫 측정점 앞은 0시 농도 0에서 시작한다고 본다. 마지막 측정점 이후(AUC 0-∞)는 소실 속도 상수로 외삽해야 하므로 여기서는 계산하지 않는다.
