# 만델브로트 집합 (글자 그림)

복소수 c마다 z ← z² + c를 40번까지 반복해, 발산하지 않으면 '#'(집합 안)으로, 빨리 발산할수록 옅은 글자로 찍는다. 복소수도 실수도 없으니 실수부·허수부를 1000배 정수로 따로 계산한다.

## 입력과 출력

- **변수**: cx, cy = 동동동현, 동동동동현 / zr, zi = 동×5현, 동×6현 / k = 동×7현

- **입력**: 없음

- **출력**: 64 × 24 글자 그림

- **새 명령**: 뚱띠, 뭉치

## 해설

- 1행: 프로그램 시작

- 2행: S = 1000 (고정소수점 배율)

- 3행: 탈출 기준 |z|² > 4 → 4000

- 4행: row = 0

- 5행: 동×13현 = ' ' (k < 2일 때 찍을 글자)

- 6행: 동×14현 = '.' (k < 3일 때 찍을 글자)

- 7…8행: 동×15현 = ':' (k < 5일 때 찍을 글자) — 곱과 덧셈으로 2줄에 나눠 쌓는다

- 9행: 동×16현 = '-' (k < 8일 때 찍을 글자)

- 10…11행: 동×17현 = '=' (k < 13일 때 찍을 글자) — 곱과 덧셈으로 2줄에 나눠 쌓는다

- 12…13행: 동×18현 = '+' (k < 40일 때 찍을 글자) — 곱과 덧셈으로 2줄에 나눠 쌓는다

- 14행: col = 0

- 15행: cx = col × 47

- 16…17행: −2100 — 곱과 덧셈으로 2줄에 나눠 쌓는다

- 18행: cx = −2.100 + col × 0.047

- 19행: cy = row × 100

- 20…21행: −1150 — 곱과 덧셈으로 2줄에 나눠 쌓는다

- 22행: cy = −1.150 + row × 0.100 (실수축을 반 칸 비켜 위아래 대칭)

- 23행: zr = 0

- 24행: zi = 0

- 25행: k = 0 (반복 횟수)

- 26행: zr²

- 27행: zi²

- 28행: −(zr² + zi²)

- 29행: 4 − |z|² < 0 → 발산, 40번 줄로

- 30행: −40

- 31행: 40번 돌아도 안 벗어나면 38번 줄로

- 32행: zi = 2·zr·zi

- 33행: zi + cy

- 34행: −zi²

- 35행: zr = zr² − zi² + cx

- 36행: k + 1

- 37행: 26번 줄로

- 38행: '#' 집합 안

- 39행: 60번 줄로

- 40행: −2

- 41행: k < 2이면 ' ' 출력

- 42행: 찍었으면 60번 줄로

- 43행: −3

- 44행: k < 3이면 '.' 출력

- 45행: 찍었으면 60번 줄로

- 46행: −5

- 47행: k < 5이면 ':' 출력

- 48행: 찍었으면 60번 줄로

- 49행: −8

- 50행: k < 8이면 '-' 출력

- 51행: 찍었으면 60번 줄로

- 52행: −13

- 53행: k < 13이면 '=' 출력

- 54행: 찍었으면 60번 줄로

- 55행: −40

- 56행: k < 40이면 '+' 출력

- 57행: 찍었으면 60번 줄로

- 58행: (빈 줄 — 다음 줄 번호를 곱으로 쓰기 쉽게 맞춘 자리)

- 59행: (빈 줄 — 다음 줄 번호를 곱으로 쓰기 쉽게 맞춘 자리)

- 60행: col + 1

- 61행: −64

- 62행: 64칸 다 찍었으면 64번 줄로

- 63행: 15번 줄로

- 64행: 줄바꿈

- 65행: row + 1

- 66행: −24

- 67행: 24줄 다 그렸으면 끝

- 68행: 14번 줄로

- 69행: 형식상 끝

## 주의

실행 걸음이 수십만이라 '실행' 버튼을 쓰라. 출력 칸 글꼴이 고정폭이라 모양이 그대로 보인다.
