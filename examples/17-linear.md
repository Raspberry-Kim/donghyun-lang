# 선형 탐색 (처음 일치하는 위치)

입력 원소를 하나씩 검사해 target의 첫 위치를 찾는다. 배열 명령 없이 입력 스트림을 순회한다.

## 입력과 출력

- **입력**: n target 다음에 정확히 n개의 정수

- **출력**: 첫 위치 1…n, 없으면 0 (기본값: 2)

- **핵심**: 중복이 있어도 첫 번째 발견을 유지

## 해설

- 1행: 프로그램 시작

- 2행: 목록 길이 n

- 3행: 찾을 정수 target

- 4행: 음수 길이 거부

- 5행: 현재 위치 i = 1

- 6행: 첫 발견 위치 = 0 (없음)

- 7행: n개를 다 읽으면 출력

- 8행: 다음 원소

- 9행: −target

- 10행: 원소 − target

- 11행: 아직 못 찾았을 때만 비교

- 12행: 기존 첫 발견 위치 보존

- 13행: 같으면 현재 위치 기록

- 14행: 위치 + 1

- 15행: 남은 개수 − 1

- 16행: 다음 원소

- 17행: 1부터 센 첫 위치, 없으면 0

- 18행: 줄바꿈

- 19행: 끝으로

- 20…62행: 결과 안내 — 문자열 "입력 오류: 목록 길이는 0 이상↵"을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동현에 쌓아서)

- 63행: 정상 종료

## 주의

입력 토큰 수를 맞춰라. 동현랭의 기존 규칙상 입력이 부족하면 0으로 읽는다.
