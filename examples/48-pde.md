# 피부 속 약물 확산 — 편미분방정식 (FTCS)

경피 패치를 붙인 피부를 9칸으로 나누고, 확산 방정식(픽의 제2법칙) ∂u/∂t = D·∂²u/∂x²를 시간은 앞으로, 공간은 가운데 차분(FTCS)으로 푼다. 표면 농도는 1, 가장 깊은 곳 너머(혈관)는 0으로 고정하고, 10·50·150·600걸음 뒤의 농도 분포를 막대로 그린다.

## 입력과 출력

- **변수**: 동현 ~ 동×9현 = 깊이별 농도 u₁…u₉ (× 10⁶)

- **입력**: 없음

- **출력**: 시점별 농도 막대 9줄 × 4, 600걸음 뒤 0.900 0.800 … 0.100

- **안정 조건**: r = D·Δt/Δx² ≤ 1/2 (여기서는 1/4)
