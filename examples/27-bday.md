# 생일 문제 (몇 명이면 생일이 겹칠까)

한 반에 n명이 있을 때 생일이 같은 사람이 적어도 한 쌍 있을 확률을 구한다. 아무도 안 겹칠 확률 q에 (366 − n)/365를 차례로 곱하고 p = 1 − q를 출력한다. 23명이면 이미 50%를 넘는다.

## 입력과 출력

- **입력**: 없음

- **출력**: n = 5 : 2.713% … n = 23 : 50.729% <- 50% 돌파! … n = 60 : 99.4xx%

- **새 명령**: 뚱띠, 또치, 뭉치, 포동이

## 해설

- 1행: 프로그램 시작

- 2행: q = 10⁶ (아무도 생일이 안 겹칠 확률 × 10⁶)

- 3…4행: 365 — 곱과 덧셈으로 2줄에 나눠 쌓는다

- 5행: n = 0

- 6행: 아직 50%를 안 넘었다는 표시 = 1

- 7행: n + 1 (사람 한 명 추가)

- 8행: −n

- 9행: 365 − n + 1 (새 사람이 피해야 할 날 수)

- 10행: q = q × (366 − n) / 365

- 11행: −q

- 12행: 10⁶

- 13행: 겹칠 확률 p = 10⁶ − q

- 14…15행: −500000 — 곱과 덧셈으로 2줄에 나눠 쌓는다

- 16행: p − 0.5

- 17행: 이미 50%를 넘겼으면 60번 줄로

- 18행: 아직 50% 미만이면 60번 줄로

- 19행: 표시를 0으로 — 처음으로 50%를 넘은 순간

- 20…25행: 강조 줄 — 문자열 "n = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 26행: n

- 27…31행: 문자열 " : "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 32행: 확률(%)

- 33…57행: 문자열 "%  <- 50% 돌파!"을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 58행: 줄바꿈

- 59행: 80번 줄로

- 60행: n이 5의 배수면 63번 줄로

- 61행: 80번 줄로

- 62행: (빈 줄 — 다음 줄 번호를 곱으로 쓰기 쉽게 맞춘 자리)

- 63…68행: 결과 줄 — 문자열 "n = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 69행: n

- 70…74행: 문자열 " : "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 75행: 포동이: p × 100%를 소수 셋째 자리까지

- 76…78행: 문자열 "%"을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 79행: 줄바꿈

- 80행: −60

- 81행: 60명까지 계산하면 끝

- 82행: 7번 줄로

- 83행: 형식상 끝

## 주의

윤년과 계절에 따른 출생 차이는 무시한 고전적인 계산이다.
