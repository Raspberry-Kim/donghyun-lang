# 세 정수 중 최댓값 (비교와 갱신)

a를 후보로 시작해 b, c와 차례대로 비교한다. 음수와 동점에도 같은 코드가 동작한다.

## 입력과 출력

- **입력**: 정수 a b c

- **출력**: 최댓값 (기본값: 12)

- **핵심**: 차이의 부호로 대소 비교

## 해설

- 1행: 프로그램 시작

- 2행: a

- 3행: b

- 4행: c

- 5행: 현재 최댓값 = a

- 6행: 비교할 값의 음수

- 7행: 현재 최댓값 − 비교할 값

- 8행: 차이가 음수면 더 큰 값으로 교체

- 9행: 비교할 값의 음수

- 10행: 현재 최댓값 − 비교할 값

- 11행: 차이가 음수면 더 큰 값으로 교체

- 12행: 세 정수의 최댓값

- 13행: 줄바꿈

- 14행: 정상 종료
