# 체표면적 BSA — 모스텔러 공식 (뉴턴법 제곱근)

항암제·소아 약용량에 쓰는 체표면적을 모스텔러 공식 BSA = √(키 × 체중 / 3600)으로 구한다. 동현랭에는 제곱근이 없으므로, 미분(접선)으로 근을 찾아가는 뉴턴법 x ← (x + n/x)/2를 직접 돌린다.

## 입력과 출력

- **입력**: (키 cm, 체중 kg) 쌍: 50·3, 110·19, 165·60, 180·80

- **출력**: 0.204, 0.761, 1.658, 2.000 m² 와 반복 횟수

- **공식**: BSA (m²) = √(키 cm × 체중 kg / 3600)

## 해설

- 1행: 프로그램 시작

- 2행: 키 (cm, 다 읽으면 0)

- 3행: 입력이 끝났으면 종료

- 4행: 체중 (kg)

- 5행: n = 키 × 체중 × 2500 / 9 — √n이 BSA × 1000

- 6행: 뉴턴법 시작값 x = n

- 7행: 반복 횟수 = 0

- 8행: n / x

- 9행: y = (x + n/x) / 2 — 접선이 x축과 만나는 점

- 10행: −x

- 11행: y < x면 아직 줄어드는 중, 13번 줄로

- 12행: 더 안 줄면 x가 √n — 16번 줄로

- 13행: x ← y

- 14행: 반복 + 1

- 15행: 8번 줄로

- 16행: 키

- 17…23행: 문자열 " cm, "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 24행: 체중

- 25…47행: 문자열 " kg -> BSA = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 48행: 체표면적 m²

- 49…69행: 문자열 " m2  (Newton "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 70행: 반복 횟수

- 71…84행: 문자열 " steps)↵"을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동현에 쌓아서)

- 85행: 2번 줄로

- 86행: 형식상 끝

## 주의

뉴턴법은 f(x) = x² − n의 접선을 따라가며 근에 다가간다. 정수 뉴턴법은 √n의 내림값에서 멈춘다.
