# 최대공약수 · 유클리드 호제법

기원전 300년 무렵 유클리드가 적어 둔, 가장 오래된 알고리즘 가운데 하나다. a = q × b + r로 나눠 (a, b) ← (b, r)을 반복하면 b가 0이 될 때의 a가 최대공약수다.

## 입력과 출력

- **입력**: 1071 462

- **출력**: 1071 = 2 x 462 + 147 … GCD = 21, LCM = 23562

- **새 명령**: 뚱띠(몫), 또치(나머지)

## 해설

- 1행: 프로그램 시작

- 2행: a 입력

- 3행: b 입력

- 4행: a × b (최소공배수용으로 보관)

- 5행: b = 0이면 28번 줄로

- 6행: a

- 7…11행: 문자열 " = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동현에 쌓아서)

- 12행: 몫

- 13…15행: 문자열 " x "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동현에 쌓아서)

- 16행: b

- 17…21행: 문자열 " + "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동현에 쌓아서)

- 22행: r = a mod b

- 23행: 나머지

- 24행: 줄바꿈

- 25행: a ← b

- 26행: b ← r

- 27행: 5번 줄로

- 28…39행: 결과 — 문자열 "GCD = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동현에 쌓아서)

- 40행: 최대공약수

- 41행: 줄바꿈

- 42…51행: 문자열 "LCM = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동현에 쌓아서)

- 52행: 최소공배수 = a × b / GCD

- 53행: 줄바꿈

- 54행: 정상 종료
