# RTC 시계 칩 해독 — 백신 냉장고 온도 로거

온도 로거의 RTC 칩이 레지스터 0x00~0x06에 BCD로 저장한 초·분·시·요일·일·월·년 7바이트를 읽어, 각 바이트의 상위 니블을 십의 자리, 하위 니블을 일의 자리로 풀고 ISO 8601 타임스탬프 2026-01-29 14:20:15를 만든다. 니블에 금지 코드가 섞이면 경고한다.

## 입력과 출력

- **입력**: 바이트 7개를 십진수로: 0x15 = 21, 0x20 = 32, 0x14 = 20, 0x04 = 4, 0x29 = 41, 0x01 = 1, 0x26 = 38

- **출력**: 레지스터 표와 타임스탬프

- **원리**: 값 = (바이트 ÷ 16) × 10 + (바이트 mod 16)

- **서브루틴**: #bits
