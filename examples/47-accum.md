# 반복 투여와 축적 — 정상 상태 도달

정맥 주사를 일정 간격 τ로 반복할 때, 직전 최저 농도에 매번 D/V가 더해지는 중첩 원리로 회차별 최고·최저 농도를 계산한다. 남는 비율 f = e^(−kτ)는 지수함수를 테일러 급수로 직접 계산한다. 정상 상태 공식 Css,max = (D/V)/(1 − f), 축적 계수 R = 1/(1 − f)와 비교한다.

## 입력과 출력

- **입력**: D 100 mg, V 25 L, t½ 8 h, τ 8 h, 10회

- **출력**: f = 0.500, 회차별 최고/최저 농도, Css,max = 8.000 mg/L, R = 2.000

- **새 명령**: 뚱띠, 포동이

## 해설

- 1행: 프로그램 시작

- 2행: 1회 용량 D (mg)

- 3행: 분포 용적 V (L)

- 4행: 반감기 t½ (h)

- 5행: 투여 간격 τ (h)

- 6행: 투여 횟수

- 7행: M = 10⁷ (급수는 한 자리 더 정밀하게)

- 8…10행: ln 2 × 10⁷ = 6931472 — 곱과 덧셈으로 3줄에 나눠 쌓는다

- 11행: x = k·τ = ln2 · τ / t½ (× 10⁶)

- 12행: e^(−x) 급수의 합 = 1

- 13행: 현재 항 = 1

- 14행: n = 1

- 15행: −x

- 16행: 항 ← 항 × (−x) / n

- 17행: 항이 0이 되면 급수 끝, 21번 줄로

- 18행: 합에 더한다

- 19행: n + 1

- 20행: 16번 줄로

- 21행: f를 10⁶ 배율로 반올림 ((합 + 5) ÷ 10)

- 22행: 이제부터 M = 10⁶

- 23…55행: 남는 비율 — 문자열 "f = e^(-k*tau) = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동동동동동동동동동동현에 쌓아서)

- 56행: f

- 57행: 줄바꿈

- 58행: 1회 투여로 오르는 농도 ΔC = D/V (× 1000)

- 59행: 직전 최저 농도 = 0

- 60행: 회차 = 0

- 61…62행: '■' — 곱과 덧셈으로 2줄에 나눠 쌓는다

- 63행: 회차 + 1

- 64행: 최고 농도 = 직전 최저 + ΔC (중첩 원리)

- 65행: 최고 × f

- 66행: M/2 = 500000

- 67행: 다음 최저 농도 = 최고 × f (반올림)

- 68행: 회차 줄 — '#' 출력 (코드값 35)

- 69행: 회차

- 70행: 탭

- 71행: 최고 농도

- 72…76행: 문자열 " / "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동동동동동동동동동동현에 쌓아서)

- 77행: 최저 농도

- 78행: 탭

- 79행: 막대 칸 = 최고 ÷ 0.5

- 80행: 돌아올 줄(84)

- 81행: 88번 줄로

- 82행: (빈 줄 — 다음 줄 번호를 곱으로 쓰기 쉽게 맞춘 자리)

- 83행: (빈 줄 — 다음 줄 번호를 곱으로 쓰기 쉽게 맞춘 자리)

- 86행: 마지막 회차면 92번 줄로

- 87행: 63번 줄로

- 91행: 88번 줄로

- 92행: −f

- 94…111행: 정상 상태 공식 — 문자열 "Css,max = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동동동동동동동동동동현에 쌓아서)

- 112행: Css,max = ΔC / (1 − f)

- 113…134행: 문자열 " mg/L,  R = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동동동동동동동동동동동동현에 쌓아서)

- 136행: 줄바꿈

## 주의

투여 간격이 반감기와 같으면 f = 1/2이라 축적 계수가 정확히 2이다. 반감기의 4~5배 시간이 지나면 정상 상태의 94~97%에 이른다는 경험칙이 막대 길이로 보인다.
