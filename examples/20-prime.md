# 소수 찾기 (꽥꽥으로 범위 N)

2부터 N까지 수마다 2, 3, 4 …로 나눠 보아 √n까지 나누어떨어지지 않으면 소수로 출력한다. 마지막에 소수 개수 π(N)을 알려 준다.

## 입력과 출력

- **입력**: 100

- **출력**: 2 3 5 7 … 97 / pi(100) = 25

- **새 명령**: 또치(나머지), 뭉치(음수면 실행)

## 해설

- 1행: 프로그램 시작

- 2행: 동현 = 범위 N

- 3행: −N

- 4행: n = 2부터

- 5행: 찾은 개수 = 0

- 6행: 나눠 볼 수 d = 2

- 7행: −d²

- 8행: n < d² 이면 약수가 없다 → 12번 줄(소수)로

- 9행: n을 d로 나눈 나머지가 0이면 소수가 아니다 → 15번 줄로

- 10행: d + 1

- 11행: 7번 줄로

- 12행: 소수 출력

- 13행: 공백

- 14행: 개수 + 1

- 15행: n = N이면 18번 줄로

- 16행: n + 1

- 17행: 6번 줄로

- 18행: 줄바꿈

- 19…21행: 개수 출력 — 문자열 "pi("을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동현에 쌓아서)

- 22행: N

- 23…30행: 문자열 ") = "을 한 글자씩 뿡뿡뿡 (곱으로 안 되는 글자는 동동동동동동현에 쌓아서)

- 31행: 소수 개수

- 32행: 줄바꿈

- 33행: 정상 종료

## 주의

d² > n인지 확인할 때 뺄셈 대신 n + (−d²)이 음수인지를 뭉치로 본다.
