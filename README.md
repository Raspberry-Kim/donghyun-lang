# 동현랭™ (Donghyun-lang)

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23689480.svg)](https://doi.org/10.5281/zenodo.23689480)

> 나는 동현이냐? … 동현이구나.

**World's Most Quirky Esoteric Language: 동현랭™**

한국어로 쓰는 난해한 프로그래밍 언어(esoteric language)다. 실행기, 플레이그라운드, 문법 안내, 예제 70개를 모두 담았다. 설치나 서버 없이 브라우저에서 바로 실행된다.

- **바로 써 보기:** [raspberry-kim.github.io/donghyun-lang](https://raspberry-kim.github.io/donghyun-lang)
- **현재 버전:** v1.55
- **언어 명세:** [SPEC.md](SPEC.md)

동현랭으로만 조종하는 열일곱 개의 작은 실험실이 있다.

- **동현초™:** [초파리 회로실험실](https://raspberry-kim.github.io/donghyun-lab1/) · FlyWire 연결망 위에서 초파리 뇌 회로를 자극하고 반응을 본다
- **동현파™:** [선충 촉각 회로실험실](https://raspberry-kim.github.io/donghyun-lab2/) · 예쁜꼬마선충의 촉각 회로에 자극을 주고 반응을 계산한다
- **동현빌™:** [마을 유행 실험실](https://raspberry-kim.github.io/donghyun-lab3/) · 실제 접촉망(Haslemere) 위에서 접종·격리를 설계하고 유행을 본다
- **동현전™:** [턴제 전략 게임](https://raspberry-kim.github.io/donghyun-lab4/) · 육해공 유닛으로 동현AI™와 겨루는 1인용 턴제 전략
- **동현콥™:** [원버튼 비행 실험실](https://raspberry-kim.github.io/donghyun-lab5/) · 고전 동굴 비행 게임을 포동이의 꼬리콥터로 난다
- **동현텐™:** [숫자 짝 실험실](https://raspberry-kim.github.io/donghyun-lab6/) · 같은 숫자나 합이 10인 짝을 지우는 숫자 놀이
- **동현워™:** [중세 전술 실험실](https://raspberry-kim.github.io/donghyun-lab7/) · 문명·병종을 골라 동현AI™와 겨루는 중세 턴제 전술
- **동현둠™:** [1인칭 슈팅 실험실](https://raspberry-kim.github.io/donghyun-lab8/) · 셰어웨어 DOOM 1편을 브라우저에서, 판·난이도·체력을 코드로
- **동현크™:** [플랫폼 액션 실험실](https://raspberry-kim.github.io/donghyun-lab9/) · 목숨·변신을 코드로 정하고 나서는 포동이의 횡스크롤 산책
- **동현몬™:** [동현몬스터 실험실](https://raspberry-kim.github.io/donghyun-lab10/) · 시작 마을·포동이의 성격·출현율을 코드로 정하고 떠나는 작은 몬스터 RPG
- **동현주™:** [얼굴 퍼즐 실험실](https://raspberry-kim.github.io/donghyun-lab11/) · 같은 얼굴 셋을 나란히 맞추면 잡히는 얼굴 판 퍼즐
- **동현심™:** [도시 만들기 실험실](https://raspberry-kim.github.io/donghyun-lab12/) · 강가 평지에 길과 전선을 깔고 작은 도시를 키운다
- **동현램™:** [도시 부수기 실험실](https://raspberry-kim.github.io/donghyun-lab13/) · 코드로 선택한 몬스터가 열두 동네를 무너뜨리는 1인용 도시 부수기
- **동현큐™:** [선 긋기 실험실](https://raspberry-kim.github.io/donghyun-lab14/) · 방식을 코드로 정하는 1인용 선 긋기 땅따먹기
- **동현닥™:** [알약 실험실](https://raspberry-kim.github.io/donghyun-lab15/) · 속도를 코드로 정하는 1인용 알약 퍼즐
- **동현삼™:** [삼국 전략 실험실](https://raspberry-kim.github.io/donghyun-lab16/) · 시작값과 규칙 수치를 코드로 정하는 1인용 삼국지 전략 시뮬레이션 게임
- **동현항™:** [항해 교역 실험실](https://raspberry-kim.github.io/donghyun-lab17/) · 시작값과 규칙 수치를 코드로 정하는 1인용 항해 · 교역 시뮬레이션 게임

열여덟 사이트 상단의 **동현의 작은 실험들** 메뉴로 서로 이동할 수 있다. 각 실험실의 출전·설정은 동현랭 코드로만 정한다.

### 조작 방법

출전·설정은 어디서나 동현랭 코드로 하고, 시작한 뒤의 조작은 실험실마다 다르다.

| 실험실 | 조작 |
|---|---|
| 동현초™ · 동현파™ · 동현빌™ | 코드만. 결과는 화면과 표로 본다 |
| 동현전™ · 동현워™ | 키보드(방향키 커서 · X 확인 · Z 취소 · S 다음 유닛 · A 정보 · Shift 사거리 · Enter 메뉴) 또는 **게임패드**. 동현AI™ 차례에 X나 Z(패드 A·B)를 누르면 빨리 감기 |
| 동현크™ | 키보드(← → 달리기 · X 점프 · Z 공격 · A 설명 · Enter 메뉴) 또는 **게임패드**. 변신은 배지로만 |
| 동현몬™ | 키보드(방향키 걷기 · X 말걸기·확인 · Z 취소 · S 동현몬 · A 상태 · Enter 메뉴) 또는 **게임패드** |
| 동현둠™ | 키보드(W·S 앞뒤 · ← → 돌기 · A·D 옆걸음 · Space 쏘기 · E 문·스위치 · Shift 달리기 · 1–5 무기 · Tab 지도) 또는 **게임패드**(십자키·왼 스틱 ↑↓ 앞뒤 · 십자키 ←→ 옆걸음 · 왼·오른 스틱 ←→ 돌기 · R1·R2 쏘기 · L1 문·스위치 · L2 달리기. 무기·지도·메뉴·저장은 키보드) |
| 동현콥™ | 마우스·터치 한 단추(누르고 있으면 오르고 떼면 내려간다) |
| 동현텐™ | 마우스·터치로 두 수를 눌러 짝 지우기, Add·Hint 단추 |

게임패드는 블루투스나 USB로 기기에 짝지어 두면 브라우저가 바로 읽는다(Gamepad API, Safari·Chrome·Firefox·아이폰 Safari). 닌텐도 배치를 기준으로, 다이아몬드 네 단추의 자리로 키보드와 짝을 맞췄다: **오른쪽(A)=X키 · 아래(B)=Z키 · 위(X)=S키 · 왼쪽(Y)=A키**, 십자·왼 스틱=방향키, +=Enter, L=Shift(동현전·동현워). 닌텐도·8BitDo(닌텐도 배열) 패드는 브라우저 표준 배치가 자리 기준이라 설정 없이 바로 A=X키·B=Z키다. 드물게 A와 B가 거꾸로 들어오는 패드는 −(Select)를 한 번 눌러 바꾸고(다시 누르면 원래대로), 선택은 패드 이름별로 브라우저에 남는다. 동현둠은 다른 짝(십자키·스틱·R1·R2·L1·L2만, 위 표)을 쓴다. 동현콥·동현텐의 게임패드는 없다. 휴대폰에서는 전·워·크·몬 네 게임이 화면 단추로도 된다.

변경 이력은 [CHANGELOG.md](CHANGELOG.md)에 있다.

## 맛보기

```
나는 동현이냐?
동현아 꽥꽥               ㅋㅋ 1번 변수(동현)에 n 입력
동동현아 도옹             ㅋㅋ 2번 변수(동동현) = 1
신중동 동현? 신중동역 도오오오오오오오옹
동동현아 동동현 동현      ㅋㅋ 동동현 = 동동현 × 동현
동현아 동현ㅠ             ㅋㅋ 동현 = 동현 − 1
신중동역 도오오오옹        ㅋㅋ 4번 줄로
뿡뿡 동동현
뿡뿡뿡
동현이구나
```

팩토리얼이다. 입력 5 → `120`, 입력 10 → `3628800`.

한 줄로 쓸 수도 있다. `~`는 줄바꿈과 같다.

```
나는 동현이냐?~뿡뿡 도오오오오옹 도오오오오오옹~뿡뿡뿡~동현이구나
```

출력: `30` (5 × 6)

## 문법 요약

### 프로그램 구조

| 요소 | 문법 | 의미 |
|---|---|---|
| 시작 | `나는 동현이냐?` | 첫 줄은 반드시 이것이다. 아니면 "넌 동현이가 아니다" 오류가 난다 |
| 끝 | `동현이구나` | 마지막 줄은 반드시 이것이다. 실행이 여기 닿으면 정상 종료한다 |
| 주석 | `ㅋㅋ` 이후 | 줄 끝까지 무시한다 |
| 원라인 | `~` | 줄바꿈과 같다 |

### 값과 식

원자를 붙여 쓰면 더하고, 공백으로 띄운 항끼리는 곱한다. 연산자 우선순위는 없고 왼쪽부터 차례로 계산한다.

| 원자 | 값 |
|---|---|
| `도옹`, `도오옹`, `도오오옹` … | 1, 2, 3 … (오의 개수 + 1) |
| `ㅠ` | −1 |
| `동현`, `동동현`, `동동동현` … | 1번, 2번, 3번 … 변수 (동의 개수 = 변수 번호, 초기값 0) |
| `꽥꽥` | 정수 하나를 입력받는다 |

| 식 | 값 |
|---|---|
| `도오오옹도옹` | 3 + 1 = 4 |
| `도오오옹 도오오옹` | 3 × 3 = 9 |
| `동현ㅠ` | 동현 − 1 |
| `도오오오오오오옹 뚱띠 도오옹` | 7 ÷ 2 = 3 (몫) |
| `도오오오오오오옹 또치 도오옹` | 7을 2로 나눈 나머지 1 |

### 명령어

| 명령 | 문법 | 동작 |
|---|---|---|
| 대입 | `동현아 <식>` | 1번 변수에 대입한다 (`동동현아`는 2번) |
| 입력 | `꽥꽥` | 정수 하나를 입력받는다 (`동현아 꽥꽥`) |
| 정수 출력 | `뿡뿡 <식>` | 값을 정수로 출력한다 |
| 문자 출력 | `뿡뿡뿡 <식>` | 값을 유니코드 문자로 출력한다 |
| 줄바꿈 | `뿡뿡뿡` | 줄바꿈을 출력한다 |
| 조건 | `신중동 <식>? <명령>` | 식이 0일 때만 명령을 실행한다 |
| 음수 조건 | `뭉치 <식>? <명령>` | 식이 음수일 때만 명령을 실행한다 |
| 이동 | `신중동역 <식>` | 해당 번호 줄로 이동한다 (1번 줄 = `나는 동현이냐?`) |
| 소수 출력 | `포동이 <식>` | 값을 1000으로 나눠 소수 셋째 자리까지 출력한다 (3142 → 3.142) |
| 중단 | `오겡끼데스까 [<식>]` | 가장 강력한 중단 명령이다 |

### 오겡끼데스까

`동현이구나`가 마지막 줄에 닿아야 끝나는 자연스러운 종료라면, `오겡끼데스까`는 어디서든 즉시 모든 것을 끝내는 외침이다.

- 실행되는 순간 출력을 비우고 종료한다. 뒤의 줄은 한 줄도 실행되지 않는다.
- 뒤에 식을 쓰면 그 값이 종료 코드가 된다. 생략하면 0이다.
- 언어 안에서는 이를 가로채거나 무를 방법이 없다.
- 종료하면 `…와타시와 겡끼데스.`라고 답한다.

## 플레이그라운드 기능

- **편집기:** 문법 색칠, 줄 번호, 실행(⌘/Ctrl + Enter), 천천히 실행 모드, 오겡끼데스까 중단 버튼. 명령은 2칸, 따로 줄에 있는 주석은 3칸으로 자동 들여쓴다.
- **예제 70개:** 11개 분류. 예제마다 줄별 `ㅋㅋ` 주석과 명세 해설이 있다.
- **아스키 변환기 (v1.5):** 문자 ↔ 코드값을 10·2·8·16진법으로 바꾸고, 코드값을 꽥꽥 입력 칸에 바로 넣는다.
- **뿡뿡 출력:** 텍스트 보기와 웹페이지 보기. 출력한 HTML을 미리볼 수 있다.
- **동현이들 (변수):** 실행 중인 변수 값을 보여 준다.
- **공유와 저장:** 코드를 담은 공유 링크 복사, `.dh` 파일 저장
- **HTML에 넣기:** `donghyun.js`를 받아 다른 웹페이지에서 `<script type="text/donghyun">`로 실행한다.
- **코드 생성기:** 문장을 입력하면 그 문장을 출력하는 동현랭 프로그램을 만들어 준다.
- **어두운 화면 모드**
