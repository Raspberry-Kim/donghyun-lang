# 동현랭™ (Donghyun-lang)

> 나는 동현이냐? … 동현이구나.

**World's Most Quirky Esoteric Language: 동현랭™**

한국어로 쓰는 난해한 프로그래밍 언어(esoteric language)다. 실행기, 플레이그라운드, 문법 안내, 예제 70개를 모두 담았다. 설치나 서버 없이 브라우저에서 바로 실행된다.

- **바로 써 보기:** [raspberry-kim.github.io/donghyun-lang](https://raspberry-kim.github.io/donghyun-lang)
- **현재 버전:** v1.52
- **언어 명세:** [SPEC.md](SPEC.md)
- **동현초™:** [초파리 회로실험실](https://raspberry-kim.github.io/donghyun-lab1/)
- **동현파™:** [선충 촉각 회로실험실](https://raspberry-kim.github.io/donghyun-lab2/)

세 사이트 상단의 **동현의 작은 실험들** 메뉴로 서로 이동할 수 있다.

변경 이력은 [CHANGELOG.md](CHANGELOG.md)에 있다.

## 맛보기

```
나는 동현이냐?
동현아 꽥꽥               ㅋㅋ 1번 변수(동현)에 n 입력
동동현아 도옹             ㅋㅋ 2번 변수(동동현) = 1
신중동 동현? 신중동역 도오오오오오오오옹
동동현아 동동현 동현      ㅋㅋ 동동현 = 동동현 × 동현
동현아 동현ㅠ             ㅋㅋ 동현 = 동현 − 1
신중동역 도오오오옹        ㅋㅋ 4번 줄로
뿡뿡 동동현
뿡뿡뿡
동현이구나
```

팩토리얼이다. 입력 5 → `120`, 입력 10 → `3628800`.

한 줄로 쓸 수도 있다. `~`는 줄바꿈과 같다.

```
나는 동현이냐?~뿡뿡 도오오오오옹 도오오오오오옹~뿡뿡뿡~동현이구나
```

출력: `30` (5 × 6)

## 문법 요약

### 프로그램 구조

| 요소 | 문법 | 의미 |
|---|---|---|
| 시작 | `나는 동현이냐?` | 첫 줄은 반드시 이것이다. 아니면 "넌 동현이가 아니다" 오류가 난다 |
| 끝 | `동현이구나` | 마지막 줄은 반드시 이것이다. 실행이 여기 닿으면 정상 종료한다 |
| 주석 | `ㅋㅋ` 이후 | 줄 끝까지 무시한다 |
| 원라인 | `~` | 줄바꿈과 같다 |

### 값과 식

원자를 붙여 쓰면 더하고, 공백으로 띄운 항끼리는 곱한다. 연산자 우선순위는 없고 왼쪽부터 차례로 계산한다.

| 원자 | 값 |
|---|---|
| `도옹`, `도오옹`, `도오오옹` … | 1, 2, 3 … (오의 개수 + 1) |
| `ㅠ` | −1 |
| `동현`, `동동현`, `동동동현` … | 1번, 2번, 3번 … 변수 (동의 개수 = 변수 번호, 초기값 0) |
| `꽥꽥` | 정수 하나를 입력받는다 |

| 식 | 값 |
|---|---|
| `도오오옹도옹` | 3 + 1 = 4 |
| `도오오옹 도오오옹` | 3 × 3 = 9 |
| `동현ㅠ` | 동현 − 1 |
| `도오오오오오오옹 뚱띠 도오옹` | 7 ÷ 2 = 3 (몫) |
| `도오오오오오오옹 또치 도오옹` | 7을 2로 나눈 나머지 1 |

### 명령어

| 명령 | 문법 | 동작 |
|---|---|---|
| 대입 | `동현아 <식>` | 1번 변수에 대입한다 (`동동현아`는 2번) |
| 입력 | `꽥꽥` | 정수 하나를 입력받는다 (`동현아 꽥꽥`) |
| 정수 출력 | `뿡뿡 <식>` | 값을 정수로 출력한다 |
| 문자 출력 | `뿡뿡뿡 <식>` | 값을 유니코드 문자로 출력한다 |
| 줄바꿈 | `뿡뿡뿡` | 줄바꿈을 출력한다 |
| 조건 | `신중동 <식>? <명령>` | 식이 0일 때만 명령을 실행한다 |
| 음수 조건 | `뭉치 <식>? <명령>` | 식이 음수일 때만 명령을 실행한다 |
| 이동 | `신중동역 <식>` | 해당 번호 줄로 이동한다 (1번 줄 = `나는 동현이냐?`) |
| 소수 출력 | `포동이 <식>` | 값을 1000으로 나눠 소수 셋째 자리까지 출력한다 (3142 → 3.142) |
| 중단 | `오겡끼데스까 [<식>]` | 가장 강력한 중단 명령이다 |

### 오겡끼데스까

`동현이구나`가 마지막 줄에 닿아야 끝나는 자연스러운 종료라면, `오겡끼데스까`는 어디서든 즉시 모든 것을 끝내는 외침이다.

- 실행되는 순간 출력을 비우고 종료한다. 뒤의 줄은 한 줄도 실행되지 않는다.
- 뒤에 식을 쓰면 그 값이 종료 코드가 된다. 생략하면 0이다.
- 언어 안에서는 이를 가로채거나 무를 방법이 없다.
- 종료하면 `…와타시와 겡끼데스.`라고 답한다.

## 플레이그라운드 기능

- **편집기:** 문법 색칠, 줄 번호, 실행(⌘/Ctrl + Enter), 천천히 실행 모드, 오겡끼데스까 중단 버튼
- **예제 70개:** 11개 분류. 예제마다 줄별 `ㅋㅋ` 주석과 명세 해설이 있다.
- **아스키 변환기 (v1.5):** 문자 ↔ 코드값을 10·2·8·16진법으로 바꾸고, 코드값을 꽥꽥 입력 칸에 바로 넣는다.
- **뿡뿡 출력:** 텍스트 보기와 웹페이지 보기. 출력한 HTML을 미리볼 수 있다.
- **동현이들 (변수):** 실행 중인 변수 값을 보여 준다.
- **공유와 저장:** 코드를 담은 공유 링크 복사, `.dh` 파일 저장
- **HTML에 넣기:** `donghyun.js`를 받아 다른 웹페이지에서 `<script type="text/donghyun">`로 실행한다.
- **코드 생성기:** 문장을 입력하면 그 문장을 출력하는 동현랭 프로그램을 만들어 준다.
- **어두운 화면 모드**
